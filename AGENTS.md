# AGENTS.md — Agent System Architecture & Tool Bindings

## 1. Overview
TrailQuest uses an agentic architecture powered by **Hermes Agent** as the central orchestrator and **Gemma** (running via DigitalOcean Inference or local Ollama) as the evaluation engine.

The agent evaluates completed, offline-buffered runs, checks path fidelity using spatial queries, visually validates landmark photos submitted by runners, and calculates reward points.

3. Tool Specifications
Tool 1: evaluate_run_navigation_accuracy
Purpose: Compares the user's recorded offline GPS trajectory against the planned route generated by OSRM.

Input Arguments:

planned_route_id (UUID)

run_id (UUID)

Execution: Runs a PostGIS Hausdorff distance calculation:

SQL
SELECT ST_HausdorffDistance(
  ST_Transform(p.route_geometry, 3857),
  ST_Transform(r.route_path, 3857)
) AS deviation_meters
FROM planned_routes p, runs r
WHERE p.id = :planned_route_id AND r.id = :run_id;
Returns: { "deviation_meters": float, "is_route_adherent": boolean } (adherent if <= 75.0 m).

Tool 2: run_gemma_vision_verifier
Purpose: Verifies whether a user-submitted photo contains the target outdoor landmark.

Input Arguments:

image_path (string)

landmark_target_description (string)

Inference Endpoint: Calls DigitalOcean Inference or Ollama endpoint serving Gemma.

Prompt Contract:

Plaintext
SYSTEM: You are the TrailQuest Outdoor Arbiter. Evaluate if the runner's photo matches the target landmark description.
TARGET: {landmark_target_description}

Respond ONLY with valid JSON:
{
  "is_match": boolean,
  "confidence": float,
  "identified_objects": string[],
  "savage_coach_remark": string
}
Tool 3: tally_quest_score
Purpose: Computes earned points and updates the database.

Logic:

Distance: 10 pts/km.

Navigation bonus: +50 pts if is_route_adherent == true.

Visual quest: +100 pts * 1.5 (running) or 1.0 (walking) if is_match == true and confidence >= 0.70.

Social quest: +15 pts per validated greeting.

Database Action: Updates quest_submissions and increments users.total_points.
